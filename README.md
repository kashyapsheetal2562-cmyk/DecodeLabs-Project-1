 # DecodeLabs Project 1 – Responsive Frontend Interface

A responsive frontend interface created as part of the DecodeLabs Full Stack Development Internship Program.

## 📌 Project Overview

This project focuses on building a clean, responsive and user-friendly web interface using fundamental frontend technologies.

The interface is designed to work smoothly across desktop, tablet and mobile screen sizes.

## 🚀 Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section
- About section
- Feature cards
- Project roadmap
- Call-to-action section
- Responsive footer
- Mobile, tablet and desktop layouts
- Basic JavaScript interactions
- Semantic HTML5 structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The website has been designed and tested for:

- Mobile devices
- Tablets
- Desktop screens

CSS Grid, Flexbox, media queries and `clamp()` have been used to create the responsive layout.
